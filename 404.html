Use it anywhere

One file, no dependencies, no network calls, CC0. Drop nyavatar.js next to your app and hash whatever identity you already have. 

<script src="https://catgirls.zone/nyavatar.js"></script>
<script>
  // full SVG markup — anime by default, or { style: "chibi" }
  container.innerHTML = nyavatar(user.email);

  // or as an image source
  img.src = nyavatar.dataUri(user.id, { size: 128, style: "chibi" });

  // or just the traits, if you want to draw it yourself
  nyavatar.traits("mia");
  // { ears: "pointy", hair: "twintails", eyes: "sparkle", … }
</script>

Deterministic means it works as an identicon: the same user gets the same face on every device, every page load, forever, without storing a single byte. It also means you can link straight to one — catgirls.zone/?seed=nyanpasu.
