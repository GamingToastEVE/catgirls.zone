catgirls.zone

Five small things, each on its own path. All of them run entirely in your browser — no accounts, no servers, nothing uploaded. Close the tab and nothing of yours went anywhere.

/tools

Developer tool belt

Base64, JWT decoding, UUIDs, hashes, a regex tester, cron parsing, timestamps, JSON formatting and a text diff. The pile of things you normally paste into somebody else's ad-riddled website.

 /wort

Daily word game

One five-letter puzzle a day, the same for everyone, derived from the date. Six guesses, a streak that survives reloads, and a spoiler-free result grid to share.

 /kaomoji

Kaomoji search

A searchable pile of (=^･ω･^=) and relatives. Type to filter, arrow keys to move, enter to copy. No network requests once the page has loaded.

 /nyanifier

Nyanifier

Text in, cat nonsense out, in four escalating levels. Deterministic — the same text always transforms the same way. Usable as a library and a command line tool too.

 /cafe

Catgirl Café

An idle game made of numbers and curves: staff, upgrades, compounding multipliers and offline earnings. Saves to your browser.

 /casino

Play-money casino

Slots, roulette and blackjack with chips that cannot be bought and refill for free. The odds are the real ones, each game shows its true house edge, and the bank panel tracks what you have actually got back against it.
